# Обновление «Европа 2026» через Codex

Источник: https://docs.google.com/document/d/1Cur6Y7qsbR_hDzeSGMHfBKdATvPSdYDt93KRQH5WdsA/edit

1. Прочитать документ полностью через Google Drive get_document, включая все вложенные вкладки и dateElementProperties. Исходный документ не менять.
2. Сохранить очищенный текст в data/source-plan.txt. Удалить даты рождения, контакты, коды брони и точный частный адрес. Не переносить необязательные альтернативы в основной план.
3. Подготовить work/candidate.json на основе data/plan.json. Сохранить ID существующих мест, посещений, расходов и переездов независимо от изменения времени/порядка. Назначить новые ID только новым сущностям. Не запускать первоначальный эвристический парсер поверх обновлённой модели: сопоставить сущности по смыслу и исходным привязкам.
4. Увеличить version и importedAt, перенести все согласованные изменения. photos.json и references.json хранятся отдельно; сохранять ранее найденные материалы. Противоречия перечислить в issues. Оплату считать подтверждённой только при явном основании.
5. Запустить `node --experimental-strip-types scripts/import-plan.mts work/candidate.json`. Проверить work/import-comparison.json. Обсудить только существенные неразрешимые противоречия; не спрашивать о бесспорных изменениях.
6. После проверки применить `node --experimental-strip-types scripts/import-plan.mts work/candidate.json --apply`. Для согласованных спорных удалений/дат/статусов можно добавить `--accept-conflicts`. Предыдущая версия сохранится в data/history, фото останутся привязанными к устойчивым ID. Не перезаписывать ручные правки в данных без проверки.
7. Прогнать scripts/check.mts (обновить ожидаемые значения только по фактам нового документа), сборку и необходимую проверку интерфейса. Затем sites-hosting с тем же project_id.

Личные заметки и отметки живут в localStorage отдельно от общего плана и сохраняются при новой публикации. Если в браузере импортирован собственный маршрут, новая опубликованная версия предлагается через сравнение, не применяется молча. Резервная копия экспортирует план, личные данные и локальную историю. Общие данные меняются только через исходники и авторизованную публикацию Sites, открытого API записи нет.

Произвольный текст можно загрузить в разделе «Мой план» и скачать для передачи Codex. Браузер не выдаёт эвристический разбор текста за достоверную синхронизацию. Прямой OAuth Google Docs не реализован.

## Демо

В «Мой план» кнопка «Проверить обновление» меняет время NEMO 12:00 → 12:30 и добавляет место на копии данных. Тот же mergePlan используется реальным импортом. Проверяются сохранённое фото и личная заметка. Рабочий маршрут демонстрация не меняет.
