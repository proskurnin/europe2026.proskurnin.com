# Европа 2026

Интерактивный семейный маршрут: 17 сентября — 4 октября 2026.

Сайт: https://europe2026.proskurnin.com/

## Возможности

- Маршрут на Google Maps и OpenStreetMap, расписание по дням и презентация.
- Бюджет, подготовка, избранное и личные заметки в браузере.
- Онлайн-прогноз погоды с явно обозначенным историческим запасным вариантом.
- Автоматический выбор следующего рейса, флаги стран и отсчёт по расписанию с учётом часовых поясов.
- Прогресс поездки и отметки состоявшихся посещений. Бортовой журнал и фактические расходы доступны владельцу и участникам.

## Запуск

Нужен Node.js 22.13 или новее.

```sh
npm ci
npm run dev
```

Для Google Maps создайте `public/maps-config.json` по примеру `public/maps-config.example.json`. Используйте собственный ключ Maps JavaScript API с ограничениями по API и разрешённым доменам. Настоящий ключ не хранится в Git. OpenStreetMap доступен без него.

## Проверка и сборка

```sh
node --experimental-strip-types scripts/check.mts
node --experimental-strip-types scripts/weather-check.mts
EUROPE_STATIC=1 npm run build
node scripts/prepare-apache-export.mjs
```

Статический сайт находится в `dist/client`. Проверяйте наличие `index.html` перед публикацией. На сервер следует переносить весь результат одной сборки; смешивать модули разных сборок нельзя. Сохраните серверный `maps-config.json` при переключении выпуска.

`server/` содержит сервис обновления статуса UT 785 и пример конфигурации Apache для `/api/ut785.json`. Без этого сервиса обратный отсчёт использует расписание из плана и сообщает об ошибке обновления.

## Маршруты между точками

`lib/logistics.ts` описывает последовательность остановок каждого дня, включая отдельные точки внутри составных прогулок. `app/google-day-route.tsx` рассчитывает участки с помощью Google Maps Routes Library, отображает линии, номера, время в пути и шаги/пересадки. При приближении города автоматически выбирается первый день в нём; другие дни доступны в списке.

Для работы требуется **Routes API**, включённый в том же Google Cloud проекте, и разрешение Routes API в ограничениях браузерного ключа. Ограничение по HTTP referrer должно сохраняться. Запросы тарифицируются Google; результаты повторно используются в памяти до 20 минут. Одновременно рассчитывается только выбранный день, участки отправляются последовательно.

Неизвестные/неопубликованные адреса оставляют явные разрывы. Пользователь может указать свой адрес: он сохраняется в localStorage и передаётся Google для расчёта, но не загружается на сервер сайта. Паром не заменяется пешеходным маршрутом. Для «Метро»/«Поезд» Google принимает предпочтение, фактический транспорт показывается в шагах. Такси означает автомобильный маршрут без вызова машины. За пределами временного окна Google расчёт транспорта маркируется как вариант на сегодня.

```sh
node --experimental-strip-types scripts/logistics-check.mts
```

## Данные маршрута

`data/plan.json` — опубликованный маршрут, `data/photos.json` — фотографии с авторством и лицензиями, `data/references.json` — справочные сведения. Процесс обновления описан в `UPDATE.md`. Исходный личный документ, история импорта, ключи и локальные настройки в репозиторий не входят.

## Подготовлено 18 сентября 2026

Обновлены исходники для основного домена, публикация на VPS ещё не подтверждена. Для выпуска необходимо обновить интерфейс, закрытую копию `data/plan.json` и `server/account/public-plan.mjs` в действующем сервисе, затем перезапустить сервис. Базу аккаунтов, видео и общих отметок сохранять. Без обновления API новый журнал не появится.

Журнал хранится в `plan.execution`. Публичная сборка содержит только город и дату последней записи; записи, расходы и исходный документ доступны через существующий API только владельцу и участникам. Новые записи журнала и фактические траты не включены в публичный репозиторий; их необходимо загрузить отдельно в закрытую копию плана.

Исходники карточки рейса: `lib/flights.ts`, `app/flight-countdown.tsx`. Карточка меняется после планового времени вылета; это не подтверждение фактического вылета. Для рейса без времени обратный отсчёт не показывается.
