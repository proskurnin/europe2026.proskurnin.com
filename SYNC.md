# Синхронизация с europe2026.proskurnin.com

Источник: https://europe2026.proskurnin.com/, проверен 15 сентября 2026 (Москва).
Восстановлены исходники из архива владельца от 9 сентября, данные сверены с опубликованной страницей.
Маршрут, бюджет, подготовка, фото, погода, локальные заметки и импорт сохранены.
Сервис рейса UT 785 доступен через серверный маршрут /api/ut785.json, который читает существующий источник.
По умолчанию используется OpenStreetMap: прежний ключ Google Maps ограничен исходным доменом. Ограничения ключа не изменялись.
Личные данные браузера автоматически между доменами не переносятся. Для переноса используется существующий экспорт/импорт резервной копии на вкладке «Мой план».

## Видеоотчёт

Страница /videos и API /api/videos сохраняют ссылки в D1 (DB, таблица trip_videos). Доступ к записям ограничен текущим пользователем из доверенного заголовка Sites. Таблица создаётся миграцией drizzle/0000_video_report.sql, которую применяет публикация Sites. Эта функция требует Worker и D1 и не входит в прежний статический сайт на пользовательском домене.
